## 🔀 How to Access & Switch Branches

To check out any specific project branch locally:

```bash
# Clone the repository
git clone https://github.com/jbs7/Misc-Apps.git
cd Misc-Apps

# Switch to the Captcha branch
git checkout captcha

# Switch to the Mizo Bible branch
git checkout mizo-bible
```
