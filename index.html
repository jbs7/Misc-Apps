1. Quick Start Guide

Step 1: Include script in your HTML page:

<script src="assets/js/captcha.js"></script>

Step 2 (A): Quick One-Liner Initialization:

captcha('#loginButton', { type: 'login' });

Step 2 (B): Full Initialization Code (Clean Allowed Values):

captcha('#targetElement', {
  type: 'custom',               // login|signin|register|signup|submit|send|pay|checkout|delete|danger|download|custom
  shape: 'circle',              // circle|square|triangle
  direction: 'horizontal',      // horizontal|vertical|diagonal|all
  size: 'md',                   // sm|md|lg|xl
  accessibility: 'on',          // on|off|always
  tooltip: true,                // true|false
  auto: true,                   // true|false
  bidirectional: true,          // true|false
  animation: true,              // true|false
  botProtection: true,          // true|false
  theme: 'auto',                // auto|dark|light
  label: 'Slide to continue',
  verifiedText: 'Successful',
  onBeforeStart: function() {   // Validation Callback: return true to unlock swipe; return false to block
    return email.value !== '' && password.value !== '';
  },
  colors: {
    dark: { primary: '#00f3ff', bg: '#0f172a' },
    light: { primary: '#0056b3', bg: '#ffffff' }
  },
  onSuccess: function() {       // Success Callback
    console.log("Verified successfully!");
  }
});

2. Complete Options & Custom Keys Reference

Option Key Type / Options Default Value Description
onBeforeStart function() null Validation callback. Return true to allow swiping; false to block & show warning.
accessibility on|off|always on 'on': 10% trigger button; 'off': hidden; 'always': exposed bottom toolbar.
shape circle|square|triangle circle Custom shape of the randomized target zone area.
direction horizontal|vertical|diagonal|all horizontal Drawing trajectory axis. Non-horizontal modes render a square canvas.
size sm|md|lg|xl md Controls container height, handle button size, and font scaling.
tooltip true|false true Displays helpful guidance tooltip on mouse hover or focus.
type login|signin|register|signup|submit|send|pay|checkout|delete|danger|download|custom custom Preset template mode setting labels & semantic colors.
auto true|false true true: auto-clicks button & hides it. false: enables button on swipe.
bidirectional true|false true Randomizes start position (Left-to-Right OR Right-to-Left swiping).
botProtection true|false true Verifies velocity variance, curve entropy & jerk to block AI/automated bots.

3. Form Pre-Validation Callback (`onBeforeSubmit` / `onBeforeStart`)

Login Form Validation (`onBeforeSubmit`)

Allows swiping first. If validation returns a custom error string, it flashes in red on the captcha bar and resets.

captcha('#valLoginBtn', {
  type: 'login',
  onBeforeSubmit: function() {
    const email = document.getElementById('loginEmail').value.trim();
    const pass = document.getElementById('loginPass').value.trim();
    if (!email) return 'Please enter valid Email';
    if (!pass) return 'Please enter Password';
    return true;
  }
});

Register Form Validation (`onBeforeSubmit`)

Returns custom message prompting user to check terms and conditions before completion.

I agree to terms 
captcha('#valRegBtn', {
  type: 'register',
  onBeforeSubmit: function() {
    const user = document.getElementById('regUser').value.trim();
    const terms = document.getElementById('regTerms').checked;
    if (!user) return 'Enter desired Username';
    if (!terms) return 'Check Terms & Conditions';
    return true;
  }
});

4. Accessibility Modes (`accessibility: on | off | always`)

Accessibility Mode: ON (`accessibility: 'on'`)

Renders 10% trigger button that expands assistive tools on click.

captcha('#a11yOnBtn', {
  type: 'login',
  accessibility: 'on'
});

Accessibility Mode: ALWAYS (`accessibility: 'always'`)

Directly exposes assistive tools at the bottom without clicking 10% button.

captcha('#a11yAlwaysBtn', {
  type: 'pay',
  accessibility: 'always'
});

Accessibility Mode: OFF (`accessibility: 'off'`)

Disables accessibility trigger & hides assistive tools completely.

captcha('#a11yOffBtn', {
  type: 'delete',
  accessibility: 'off'
});
